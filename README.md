# MIS Solutions Website

A clean, responsive static website for MIS Solutions, focused on practical cloud modernization, Microsoft 365 governance, and responsible AI consulting.

## Design

The site uses the MIS navy and orange palette with a warm paper background, a simplified single-page information architecture, and one consistent component and spacing system. The full MIS Solutions wordmark is intentionally prominent in the header on desktop and mobile.

## Files

- `index.html` — semantic page structure and content
- `styles.css` — responsive visual system and components
- `script.js` — accessible mobile navigation and current year
- `assets/` — MIS Solutions logo assets
- `favicon.svg` — browser icon

## Local preview

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000/>.

## Publishing

The repository is designed for GitHub Pages and includes `.nojekyll`. Publish the `main` branch from the repository root.
